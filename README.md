# SILK — Organisational Intelligence Platform

A cinematic, responsive storytelling website for SILK.

## Preview

Open `index.html` directly in a browser, or serve the repository locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Image assets

Place the supplied artwork in the `assets` directory:

- `assets/world-map-gold.png` — gold world map
- `assets/south-africa-gold.png` — South Africa map
- `assets/logo.png` — SILK logo
- `assets/founder.jpg` — founder portrait

The current HTML is fully styled and functional without these optional files, and will display fallbacks when an image is unavailable.
